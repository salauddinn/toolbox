# Rank technical candidates and let the developer select

ToolBox will rank up to three Domain Candidates using measurable code evidence and may identify the safest technical candidate, but it will not claim to know which domain is most important to the business. The developer selects or confirms the Domain Candidate and may add Modernization Intent before generation because source code reveals technical structure, not organizational priority.

## Consequences

Product language must distinguish technical suitability from business importance. Candidate evidence and conflicting signals remain visible, and no Modernization Sequence begins until the developer makes the selection.
